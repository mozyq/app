mozyq.org

The best mosaic generator I made last night.

# Install mozyq pip install mozyq # Grab some photos mkdir photos && seq 999 | xargs -I {} -n 1 -P 32 wget https://picsum.photos/630 -O photos/{}.jpg # Generate frames for video mzq json photos/1.jpg && mzq frames mzq.json frames # Install ffmpeg sudo apt install ffmpeg # Generate video from frames ffmpeg -y -framerate 16 -i frames/%04d.jpg -c:v libx264 -pix_fmt yuv420p output.mp4
