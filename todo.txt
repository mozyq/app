DEMO:
    I want to create a demo using the Google Emoji Noto Color emoji font.
    You need to:
        1. Download the font.
        2. Generate a folder `emojis` and convert the font into images the mzq command can use.
        3. Generate a short simple emojis.mp4 using the mzq command.
